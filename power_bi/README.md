# Power BI Dashboard Files

Due to GitHub's file size limit (25 MB), the full `.pbix` file containing pre-loaded data (20.5M+ records) is hosted externally on Google Drive.

### 📥 Download Options

* **Full Dashboard (.pbix with Data):**  
  [👉 Download NYC Ride-Hailing Analytics Dashboard (.pbix)](https://drive.google.com/file/d/12wPvxXbD_3mZ42fAhaPTxWyNRwAVPy2-/view?usp=sharing)

* **Dashboard Template (.pbit without Data):**  
  You can download the `nyc_ride_hailing_dashboard.pbit` file directly from this repository folder. When opened, it will connect to your local PostgreSQL instance and load the data dynamically.

### 📊 Dashboard Features & Pages
1. **Overview:** Company Market Share, Revenue Breakdown, Net Margin Waterfall Chart.
2. **Operations:** NYC Spatial Map (Shape Map), Top Zones, Demand & Wait Time Analysis.
3. **Economics:** Trip Distance vs. Fare Scatter Plot, Revenue by Time Window, Weekday vs. Weekend Analysis.
